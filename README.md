# Schedule Change Notification Bot

## О проекте
Приложение автоматически обрабатывает файл с изменениями расписания, находит замены для выбранной группы и отправляет их пользователю через бота.

## Задача
Проект решает проблему ручного поиска замен в общем файле расписания. Пользователю не нужно самостоятельно искать свою группу — сервис делает это автоматически и отправляет только нужную информацию.

## Функциональность
- загрузка и обработка файла с изменениями расписания
- поиск нужной учебной группы
- фильтрация замен только для выбранной группы
- отправка найденных изменений через бота
- запуск через Docker / Docker Compose

## Стек
- Java
- Maven
- Docker
- Docker Compose

## Как запустить
1. Склонировать репозиторий
2. Собрать проект:
   mvn clean package
3. Запустить:
   docker compose up --build

## Что реализовал лично
- логику обработки файла с заменами
- поиск и фильтрацию замен по группе
- интеграцию с ботом для отправки уведомлений
- docker-конфигурацию для локального запуска
